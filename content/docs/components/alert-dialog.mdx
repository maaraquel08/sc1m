## Installation

<PMCommand exec="shadcn@latest add @sc1m/alert-dialog" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  AlertDialog,
  AlertDialogTrigger,
  AlertDialogContent,
  AlertDialogTitle,
  AlertDialogDescription,
  AlertDialogClose,
} from "@/components/ui/alert-dialog";
```

## Composition

Every part is a separate export. `AlertDialog` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  AlertDialog
    AlertDialogTrigger
    AlertDialogContent
      AlertDialogTitle
      AlertDialogDescription
      AlertDialogClose
`}</Composition>

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
