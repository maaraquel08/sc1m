## Installation

<PMCommand exec="shadcn@latest add @sc1m/otp-field" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import { OTPField, OTPFieldInput } from "@/components/ui/otp-field";
```

## Composition

Every part is a separate export. `OTPField` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  OTPField
    OTPFieldInput
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Otp Field](https://base-ui.com/react/components/otp-field) — see its reference for the full keyboard map.

- Disabled parts mute their contents rather than the element, keeping the focus ring at full strength where the part stays focusable.
