## Installation

```bash
npx shadcn@latest add @sc1m/checkbox
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
```
