## Installation

<PMCommand exec="shadcn@latest add @sc1m/fieldset" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import { Fieldset, FieldsetLegend } from "@/components/ui/fieldset";
```

## Composition

Every part is a separate export. `Fieldset` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Fieldset
    FieldsetLegend
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Fieldset](https://base-ui.com/react/components/fieldset) — see its reference for the full keyboard map.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
