## Installation

<PMCommand exec="shadcn@latest add @sc1m/menu" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Menu,
  MenuTrigger,
  MenuContent,
  MenuItem,
  MenuCheckboxItem,
  MenuCheckboxItemIndicator,
  MenuRadioGroup,
  MenuRadioItem,
  MenuRadioItemIndicator,
  MenuSeparator,
  MenuGroup,
  MenuGroupLabel,
  MenuSubmenuRoot,
  MenuSubmenuTrigger,
} from "@/components/ui/menu";
```

## Composition

Every part is a separate export. `Menu` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Menu

    MenuContent

      MenuSeparator
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Menu](https://base-ui.com/react/components/menu) — see its reference for the full keyboard map.

- Decorative glyphs are `aria-hidden`, so they are not announced.
- Disabled parts mute their contents rather than the element, keeping the focus ring at full strength where the part stays focusable.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
