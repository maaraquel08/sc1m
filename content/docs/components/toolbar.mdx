## Installation

<PMCommand exec="shadcn@latest add @sc1m/toolbar" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Toolbar,
  ToolbarButton,
  ToolbarLink,
  ToolbarSeparator,
  ToolbarGroup,
  ToolbarInput,
} from "@/components/ui/toolbar";
```

## Composition

Every part is a separate export. `Toolbar` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Toolbar
    ToolbarGroup
      ToolbarButton
    ToolbarSeparator
    ToolbarLink
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Toolbar](https://base-ui.com/react/components/toolbar) — see its reference for the full keyboard map.

- Keyboard focus draws a 2px ring in `--ring`, never removed — only shown on `:focus-visible`, so a pointer press does not paint one.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
