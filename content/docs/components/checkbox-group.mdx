## Installation

```bash
npx shadcn@latest add @sc1m/checkbox-group
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { CheckboxGroup } from "@/components/ui/checkbox-group";
```
