## Installation

<PMCommand exec="shadcn@latest add @sc1m/menubar" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Menubar,
  MenubarMenu,
  MenubarTrigger,
  MenubarContent,
  MenubarItem,
  MenubarSeparator,
  MenubarGroup,
  MenubarGroupLabel,
} from "@/components/ui/menubar";
```

## Composition

Every part is a separate export. `Menubar` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Menubar
    MenubarMenu
      MenubarTrigger
      MenubarContent
        MenubarItem
        MenubarSeparator
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Menubar](https://base-ui.com/react/components/menubar) — see its reference for the full keyboard map.

- Disabled parts mute their contents rather than the element, keeping the focus ring at full strength where the part stays focusable.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
