## Installation

<PMCommand exec="shadcn@latest add @sc1m/meter" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Meter,
  MeterTrack,
  MeterIndicator,
  MeterLabel,
  MeterValue,
} from "@/components/ui/meter";
```

## Composition

Every part is a separate export. `Meter` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Meter
    MeterLabel
    MeterValue
    MeterTrack
      MeterIndicator
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Meter](https://base-ui.com/react/components/meter) — see its reference for the full keyboard map.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
