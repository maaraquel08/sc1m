## Installation

```bash
npx shadcn@latest add @sc1m/slider
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { Slider, SliderLabel, SliderValue } from "@/components/ui/slider";
```
