## Installation

<PMCommand exec="shadcn@latest add @sc1m/popover" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Popover,
  PopoverTrigger,
  PopoverContent,
  PopoverTitle,
  PopoverDescription,
} from "@/components/ui/popover";
```

## Composition

Every part is a separate export. `Popover` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Popover
    PopoverTrigger
    PopoverContent
      PopoverTitle
      PopoverDescription
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Popover](https://base-ui.com/react/components/popover) — see its reference for the full keyboard map.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
