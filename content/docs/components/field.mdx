## Installation

```bash
npx shadcn@latest add @sc1m/field
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import {
  Field,
  FieldLabel,
  FieldDescription,
  FieldError,
  FieldControl,
} from "@/components/ui/field";
```
