## Installation

<PMCommand exec="shadcn@latest add @sc1m/toast" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

```tsx lineNumbers
import {
  ToastProvider,
  useToastManager,
  createToastManager,
```

## Composition

Every part is a separate export. `ToastProvider` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  ToastViewport

      ToastClose
  ToastProvider

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Toast](https://base-ui.com/react/components/toast) — see its reference for the full keyboard map.

- Keyboard focus draws a 2px ring in `--ring`, never removed — only shown on `:focus-visible`, so a pointer press does not paint one.
- Every transition is dropped under `prefers-reduced-motion`.
