## Installation

<PMCommand exec="shadcn@latest add @sc1m/autocomplete" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Autocomplete,
  AutocompleteInput,
  AutocompleteContent,
  AutocompleteList,
  AutocompleteItem,
  AutocompleteEmpty,
} from "@/components/ui/autocomplete";
```

## Composition

Every part is a separate export. `Autocomplete` owns state; the rest are
presentational and must appear in this order.

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Autocomplete](https://base-ui.com/react/components/autocomplete) — see its reference for the full keyboard map.

- Keyboard focus draws a 2px ring in `--ring`, never removed — only shown on `:focus-visible`, so a pointer press does not paint one.
- Disabled parts mute their contents rather than the element, keeping the focus ring at full strength where the part stays focusable.
