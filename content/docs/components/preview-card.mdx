## Installation

```bash
npx shadcn@latest add @sc1m/preview-card
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { PreviewCard, PreviewCardTrigger, PreviewCardContent } from "@/components/ui/preview-card";
```
