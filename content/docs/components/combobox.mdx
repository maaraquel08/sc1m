## Installation

```bash
npx shadcn@latest add @sc1m/combobox
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import {
  Combobox,
  ComboboxInput,
  ComboboxContent,
  ComboboxList,
  ComboboxItem,
  ComboboxEmpty,
} from "@/components/ui/combobox";
```
