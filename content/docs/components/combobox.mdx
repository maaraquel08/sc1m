## Installation

<PMCommand exec="shadcn@latest add @sc1m/combobox" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  Combobox,
  ComboboxInput,
  ComboboxContent,
  ComboboxList,
  ComboboxItem,
  ComboboxEmpty,
} from "@/components/ui/combobox";
```

## Composition

Every part is a separate export. `Combobox` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  Combobox
    ComboboxInput
    ComboboxContent
      ComboboxEmpty
      ComboboxList
        ComboboxItem
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Combobox](https://base-ui.com/react/components/combobox) — see its reference for the full keyboard map.

- Keyboard focus draws a 2px ring in `--ring`, never removed — only shown on `:focus-visible`, so a pointer press does not paint one.
- Disabled parts mute their contents rather than the element, keeping the focus ring at full strength where the part stays focusable.
