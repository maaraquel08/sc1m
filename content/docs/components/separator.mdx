## Installation

<PMCommand exec="shadcn@latest add @sc1m/separator" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Separator](https://base-ui.com/react/components/separator) — see its reference for the full keyboard map.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.

<SpecTable
  columns={[tokenColumns[0], tokenColumns[2]]}
