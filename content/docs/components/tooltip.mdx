## Installation

```bash
npx shadcn@latest add @sc1m/tooltip
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { TooltipProvider, Tooltip } from "@/components/ui/tooltip";
```
