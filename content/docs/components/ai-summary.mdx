## Installation

```bash
npx shadcn@latest add @sc1m/ai-summary
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts`.

## Usage

```tsx
import {
  AiSummary,
  AiSummaryLabel,
  AiSummaryText,
  AiSummarySparkle,
} from "@/components/ui/ai-summary";
```
