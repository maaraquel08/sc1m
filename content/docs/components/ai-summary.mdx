## Installation

<PMCommand exec="shadcn@latest add @sc1m/ai-summary" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  AiSummary,
  AiSummaryLabel,
  AiSummaryText,
  AiSummarySparkle,
} from "@/components/ui/ai-summary";
```

## Composition

Every part is a separate export. `AiSummary` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  AiSummary
    AiSummaryLabel
    AiSummaryText
`}</Composition>

## Accessibility

- Decorative glyphs are `aria-hidden`, so they are not announced.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
