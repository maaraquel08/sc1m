## Installation

```bash
npx shadcn@latest add @sc1m/toggle-group
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import { ToggleGroup } from "@/components/ui/toggle-group";
```
