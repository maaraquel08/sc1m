## Installation

```bash
npx shadcn@latest add @sc1m/scroll-area
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import {
  ScrollArea,
  ScrollAreaViewport,
  ScrollAreaScrollbar,
  ScrollAreaThumb,
  ScrollAreaContent,
  ScrollAreaCorner,
} from "@/components/ui/scroll-area";
```
