## Installation

<PMCommand exec="shadcn@latest add @sc1m/scroll-area" />

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`. For the manual route — prerequisites,
`components.json`, and app-level setup — see [Installation](/docs/installation).

## Usage

```tsx lineNumbers
import {
  ScrollArea,
  ScrollAreaViewport,
  ScrollAreaScrollbar,
  ScrollAreaThumb,
  ScrollAreaContent,
  ScrollAreaCorner,
} from "@/components/ui/scroll-area";
```

## Composition

Every part is a separate export. `ScrollArea` owns state; the rest are
presentational and must appear in this order.

<Composition>{`
  ScrollArea
    ScrollAreaViewport
    ScrollAreaScrollbar
      ScrollAreaThumb
`}</Composition>

## Accessibility

Behaviour, focus management, and ARIA wiring come from [Base UI's Scroll Area](https://base-ui.com/react/components/scroll-area) — see its reference for the full keyboard map.

## Design tokens

The component reads semantic tokens only — no raw colour, radius, or
duration appears in its source. Override the token, not the component.
