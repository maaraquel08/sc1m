## Installation

```bash
npx shadcn@latest add @sc1m/select
```

This also merges the [token layer](/docs/foundations/tokens) and installs
`src/lib/cn.ts` plus `@base-ui/react`.

## Usage

```tsx
import {
  Select,
  SelectValue,
  SelectGroup,
  SelectGroupLabel,
  SelectTrigger,
  SelectContent,
  SelectItem,
} from "@/components/ui/select";
```
